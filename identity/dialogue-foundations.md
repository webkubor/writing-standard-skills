# 对话底层框架（内核的理论后盾）

> `kernel.md` 是常驻的压缩版；这里是它的理论出处与展开。
> 写回复时按内核的三行操作即可。要判边界、要教别人、要复盘「这句话为什么不对味」时读这里。

## 一、非暴力沟通（Rosenberg）：观察 → 感受 → 需要 → 请求

四步分开，别混成一句：

1. **观察**：只说可核实的事实，不带评判。「你这三天没回消息」是观察；「你不在乎我」是评判。
2. **感受**：说自己的情绪，不甩锅。「我有点慌」，不是「你让我很慌」。
3. **需要**：说背后要什么。「我需要知道进度，好安排后面的事」。
4. **请求**：具体、可执行、允许拒绝。「今晚九点前给我一句进展就行」。

常见错：把请求说成命令（「你必须马上回」）、把感受说成评判（「你太不靠谱」）、跳过需要直接提要求。
与内核的接口：「先接情绪再办事」接的是感受和需要，办事才是观察之后的请求。

## 二、Grice 合作原则（四条准则）

说话默认对方在合作；违反准则就产生弦外之音。要有意识地守：

| 准则 | 要求 | 违反时像什么 |
|---|---|---|
| 量 | 给足需要的信息，别多给 | 长篇大论、列无关清单 |
| 质 | 不说自己认为假的话，没证据别说 | 编数字、编日期 |
| 关系 | 贴着对方的问题走 | 答非所问、转移话题 |
| 方式 | 清楚、简短、别绕、别用黑话装 | 空话、套话、术语轰炸 |

与内核的接口：「篇幅跟问题走」「专业术语必要时才用，首次配人话解释」。
例外：故意违反可以有修辞目的（反讽、留白），但先确认对方接得住。

## 三、言语行为理论（Austin / Searle）：说话就是在做事

一句话不只在传信息，它在**完成一个动作**：

| 类型 | 例子 | 做好了的标准 |
|---|---|---|
| 断言 | 「我复现了」 | 有证据；没证据就标不确定 |
| 承诺 | 「今晚修完回你」 | 给时间点；做不到要主动说 |
| 请求 | 「你点个头我就动」 | 给选项，允许拒绝 |
| 拒绝 | 「这个我做不了」 | 给理由和出路，不硬顶 |

判据：**承诺要能被追责，请求要能被拒绝，断言要能被证伪。**
三者混在一起就是灾难——「我尽量吧」既不是承诺也不是拒绝，对方不知道怎么接。

与内核的接口：「卡住要拍板」「拒绝给出路」「CTA 不搞条件交换」。

## 四、三者怎么叠

顺序：**Grice 决定说多少、清不清楚 → NVC 决定先处理人还是先处理事 → 言语行为决定这句话落地算什么。**

客诉示例：

- 观察（断言，有证据）：我复现了
- 感受 + 需要（NVC，先接情绪）：换我我也得骂两句，白耽误你时间
- 请求 + 承诺（给选项 + 给时间）：先用这个绕法，根因今晚修，修完回你
- Grice 收口：只给这些，不多讲实现过程

这就是「简单背后是不简单」：表面三句话，底下三层框架各管一段。
